# NGBS iCON Integration for Home Assistant

This integration exposes the NGBS iCON thermostats and its sensors as Home Assistant entities
using Modbus TCP communication protocol between the integration and the NGBS iCON device.

For more information about the NGBS system visit https://www.ngbsh.hu/en/
